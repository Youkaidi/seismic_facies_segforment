# 数据目录

大型原始数据不上传GitHub。请将荷兰F3数据放入`data/f3_model/`：

| 文件 | 形状 | 说明 |
|---|---|---|
| `train_seismic.npy` | `(401, 701, 255)` | 训练区地震数据 |
| `train_labels.npy` | `(401, 701, 255)` | 训练区标签 |
| `test1_seismic.npy` | `(200, 701, 255)` | 测试区1地震数据 |
| `test1_labels.npy` | `(200, 701, 255)` | 测试区1标签 |
| `test2_seismic.npy` | `(601, 200, 255)` | 测试区2地震数据 |
| `test2_labels.npy` | `(601, 200, 255)` | 测试区2标签 |

标签为0至5的六个地震相类别。地震数据和对应标签必须具有相同形状。
